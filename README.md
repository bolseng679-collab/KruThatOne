# 🎓 English for Education Studies I — ប្រព័ន្ធសិក្សាអនឡាញ (E-Learning Platform)

កម្មវិធីសិក្សាភាសាអង់គ្លេសដែលបាន Clone មកពីប្រព័ន្ធបណ្តុះបណ្តាលគ្រូបឋមសិក្សា (PLP EdTech — `kru.plpedtech.com`) សម្រាប់វគ្គសិក្សា **«English for Education Studies I»** រួមមានខ្លឹមសារដើម 100% (ចំនួន ៩៣៨ មេរៀន, ៧ ម៉ូឌុល, ៥៨ តេស្ត/Quiz)។

---

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

1. **ខ្លឹមសារដើម ១០០% (100% Full Course Content):**
   - **មេរៀនសរុប ៩៣៨ មេរៀន** បែងចែកជា ៧ ម៉ូឌុលធំៗ និង ៣១ សប្តាហ៍។
   - ៥៧០ មេរៀនអាន (Reading) ជាមួយអត្ថបទ រូបភាព និងតារាងពាក្យគន្លឹះ។
   - ១៧៥ មេរៀនស្លាយអន្តរកម្ម (Interactive Slideshows & Gap-fills) មានសំណួរជាង ២,១០០ សំណួរ។
   - ១៣៥ កិច្ចការសរសេរ (Guided Writing Tasks) ជាមួយលក្ខខណ្ឌ AI Rubric។
   - ៥៨ តេស្តវាយតម្លៃ (Pretests, Lesson Tests & Final Assessment)។

2. **ប្រព័ន្ធចាក់សោមេរៀន (Sequential Progression Gating):**
   - **មិនអាចរំលងមេរៀនបានឡើយ៖** សិស្សត្រូវតែរៀន និងឆ្លងកាត់មេរៀនមុនៗឱ្យចប់សព្វគ្រប់ជាមុនសិន ទើបប្រព័ន្ធបើកសោរមេរៀនបន្ទាប់។
   - **លក្ខខណ្ឌតេស្ត ≥ ៨០%៖** រាល់ការធ្វើតេស្ត (Quiz) សិស្សត្រូវតែទទួលបានពិន្ទុ **៨០% ឡើងទៅ** ទើបអាចបន្តទៅមេរៀនបន្ទាប់បាន។ ប្រសិនបើក្រោម ៨០% សិស្សត្រូវតែធ្វើតេស្តសារថ្មីរហូតដល់បាន ៨០%។

3. **ការចុះឈ្មោះដោយប្រើលេខកូដ ១១ ខ្ទង់ (11-Digit Teacher Code Auth):**
   - សិស្សបង្កើតគណនីដោយគ្រាន់តែបញ្ចូលឈ្មោះ ឈ្មោះគណនី ពាក្យសម្ងាត់ និង **លេខកូដ ១១ ខ្ទង់** ដែលទទួលបានពីលោកគ្រូ `teacherThat`។
   - លេខកូដគំរូក្នុងប្រព័ន្ធ៖ `12345678901`, `98765432109`, `40603712345`។

4. **ផ្ទាំងគ្រប់គ្រងសម្រាប់លោកគ្រូ Admin (Admin Dashboard):**
   - តាមដានស្ថិតិសិស្សទាំងអស់ (ចំនួនសិស្ស, ភាគរយវឌ្ឍនភាពមធ្យម, ចំនួនតេស្តដែលជាប់)។
   - មើលវឌ្ឍនភាពលម្អិតរបស់សិស្សម្នាក់ៗ (មេរៀនបច្ចុប្បន្ន, ភាគរយ % រៀន, លេខកូដដែលបានប្រើ)។
   - បង្កើត និងគ្រប់គ្រងលេខកូដ ១១ ខ្ទង់ថ្មី (បង្កើតដោយស្វ័យប្រវត្ត ឬកំណត់លេខកូដដោយខ្លួនឯង)។
   - កំណត់វឌ្ឍនភាពសិស្សឡើងវិញ (Reset Progress) ប្រសិនបើចាំបាច់។

5. **វិញ្ញាបនបត្របញ្ជាក់ការសិក្សា (Certificate of Completion):**
   - នៅពេលសិស្សរៀនចប់សព្វគ្រប់ទាំង ៩៣៨ មេរៀន និងប្រឡងជាប់ Final Assessment ប្រព័ន្ធនឹងផ្ដល់ជូននូវ **វិញ្ញាបនបត្រផ្លូវការ** ដោយស្វ័យប្រវត្តិ។
   - បង្ហាញឈ្មោះពេញរបស់សិស្ស សាលារៀន ឈ្មោះវគ្គសិក្សា ឈ្មោះលោកគ្រូ `teacherThat` កាលបរិច្ឆេទ លេខកូដសម្គាល់ និងត្រាបញ្ជាក់ផ្លូវការ (Official Verified Seal)។
   - មានប៊ូតុង **បោះពុម្ព / ទាញយកជា PDF (Print & Save PDF)** ទម្រង់ A4 Landscape យ៉ាងស្រស់ស្អាត។
   - ក្នុង Admin Dashboard លោកគ្រូក៏អាចមើល និងបោះពុម្ពវិញ្ញាបនបត្រជូនសិស្សដែលរៀនចប់បានភ្លាមៗផងដែរ។

## 🚀 របៀបតម្លើង និងដំណើរការ (How to Run)

### ១. តម្រូវការជាមុន (Prerequisites)
- កុំព្យូទ័រមានដំឡើង [Node.js](https://nodejs.org/) (កំណែ 18 ឡើងទៅ)

### ២. ការតម្លើងបណ្ណាល័យ (Installation)
បើក Terminal / PowerShell ក្នុងថតគម្រោងនេះ រួចវាយពាក្យបញ្ជា៖
```bash
npm run install-all
```
*(ឬបើក PowerShell នៅលើ Windows: `npm.cmd run install-all`)*

### ៣. ដំណើរការកម្មវិធី (Run Development)
```bash
npm run dev
```
- កម្មវិធី Frontend ដំណើរការលើ៖ `http://localhost:3000`
- Backend API Server ដំណើរការលើ៖ `http://localhost:5000`

### ៤. ដំណើរការជាលក្ខណៈ Production
```bash
npm run build
npm start
```
ចូលទៅកាន់ `http://localhost:5000` នោះអ្នកអាចប្រើប្រាស់កម្មវិធីពេញលេញបានភ្លាមៗ!

## 📤 របៀប Upload កូដទៅកាន់ GitHub (How to Push to GitHub)

ដើម្បីយកកូដគម្រោងនេះទៅដាក់លើ GitHub របស់អ្នក សូមអនុវត្តតាមជំហានខាងក្រោម៖

1. បង្កើត Repository ថ្មីមួយនៅលើគេហទំព័រ [GitHub](https://github.com/new) (ឧទាហរណ៍ដាក់ឈ្មោះថា `english-for-education-studies-1`)។
2. បើក Terminal ឬ PowerShell ក្នុងថត `d:\clone add learning english` រួចវាយ៖

```bash
# ១. ចាប់ផ្តើម git
git init

# ២. បញ្ចូលឯកសារទាំងអស់
git add .

# ៣. Commit កូដ
git commit -m "Initial commit: Clone English for Education Studies I LMS"

# ៤. ប្តូរឈ្មោះ branch ទៅ main
git branch -M main

# ៥. ភ្ជាប់ទៅកាន់ GitHub Repository របស់អ្នក (ប្តូរ <your-username> និង <your-repo>)
git remote add origin https://github.com/<your-username>/english-for-education-studies-1.git

# ៦. Push កូដឡើងទៅ GitHub
git push -u origin main
```
